# 连线绘制规则

## 锚点

- 起点：有明确操作时，连接对应控件朝向路径一侧的边缘中点。
- 终点：流程只要求进入目标页面时，可连接该页面任意一侧边缘上的合适位置，不必固定在边缘中点；优先与起点水平或垂直对齐。
- 流程明确指向某个控件或判断节点时，连接对应对象，不为减少拐弯而改连其他对象。
- 自动跳转、超时失效等无操作入口 → 可连页面外层 Frame。
- 判断节点：“是/继续”从右侧顶点出；“否/失败”从顶部或底部顶点出，以图面清晰为准。

## 连线

- 只用水平或垂直连线，不使用斜线。
- 描边粗细为 2，颜色为 #04BF6A，优先绑定 color/flow。
- 页面间距调整完成后，允许连线穿过起点页面及中间页面，不为避开页面而再次挪页或增加拐弯。
- 先确定起点控件和目标对象，再比较不同连接位置与路径，不提前固定出线方向。
- 优先尝试水平或垂直直连。起点可选择控件不同侧的边缘中点；目标为页面时，终点可选择页面边缘上与起点对齐的位置。
- 无法直连时，比较“先横后竖”和“先竖后横”两种一次拐弯路径；均不可行时，再尝试两次及以上拐弯。
- 中间页面不作为绕行障碍；线段交叉不作为增加拐弯的理由。
- 在连接对象正确、符合其他连线规则的路径中，选择拐弯最少的；拐弯次数相同时，选择总长度最短的。
- 不在空白区域增加多余折点，不无故向远离目标的方向绕行。
- 连线可以交叉，但不得重叠；相邻且平行的线段至少间隔 40px。
- 连线不得沿画板边缘重合，箭头必须接到目标页面或控件边缘。
- 标签在线路确定后放置，不为固定标签位置而增加折点。
- 连线显示在页面上方，穿过页面的部分保持可见；标签显示在连线上方。

## 端点


| 位置  | Plugin API          |
| --- | ------------------- |
| 起点  | `CIRCLE_FILLED`     |
| 终点  | `ARROW_EQUILATERAL` |


在 `vectorNetwork.vertices` 上分别设置起点与终点样式，中间顶点设为 `NONE`。

设置端点样式后，矢量外框可能变大，需校正 `x/y`，使连线起点仍紧贴目标锚点。

## 标签

- 标签放在连线经过的相邻页面之间、判断节点之间或判断节点与页面之间的空隙中。
- 有多个符合条件的空隙时，选择沿连线方向离起点最近的一处。
- 标签中心对齐该空隙内的线段中点，不覆盖页面或判断节点



## 判断节点



### 位置

- 水平居中于相邻两列页面；竖直居中于左侧页面。
- 放置判断节点时，先相邻两页间距改为 `200 + 页宽 + 200`，再放节点，避免和页面重叠。



### 菱形与文字居中

`Rectangle` 旋转 45° 后，其中心可能与文字中心错位。

推荐算法（组件外框边长为 `W`，`Rectangle` 旋转后的对角线为 `W`）：

1. `side = W / √2`，正方形 `resize(side, side)`，`cornerRadius = 16`
2. `rotation = 45`
3. 将旋转后 `Rectangle` 的实际中心对准组件中心（常见写法：`x = (W - side*√2)/2`，`y = W/2`，再按实测 `absoluteBoundingBox` 微调）
4. 文字层放在组件几何中心，`textAlignHorizontal/Vertical = CENTER`

验收：`Rectangle` 中心与文字中心重合（偏移约 0）。
