# 示例

## 示例 1 — 线性

**用户：** 帮我生成「返回」线性图标

**应做：**

1. 风格 = `线性`，尺寸 = `24`，语义 = `返回` ，`描边` = `2` ，颜色 = `#333`
2. 检索6个图标库；每个库写入 1 个图标组件。
3. 图标 `cornerRadius` 可调。
4. 图标命名如 `iconpark-back-24` 。
5. 新建画板 `icons-返回`，将图标组件放入画板。
6. 回复画板链接 + 组件名 + 跳过项。

## 示例 2 — 面性

**用户：** 帮我设计「复制」的面性图标

**应做：**

1. 风格 = `面性` 无官方面性的源则用线性代替，尺寸 = `24`，语义 = `复制` ，颜色 = `#333`
2. 检索6个图标库；每个库写入 1 个图标组件。
3. 图标 `cornerRadius` 可调。
4. 「复制」这类两层纸叠放的图标：拆成前后两个圆角矩形（可命名为 Back / Front），方便改圆角。
5. 图标命名如 `iconpark-copy-24` 。
6. 新建画板 `icons-复制`，将图标组件放入画板。
7. 回复画板链接 + 组件名 + 跳过项。

## 示例 3 — 其它尺寸

**用户：** 输出铃铛的线性图标，尺寸 `48`

**应做：**

1. 先做符合需求的尺寸 `24` 图标。
2. 再同比例缩放至 `48`（`rescale(2)` ）。
3. 图标命名如 `lucide-bell-48` 等。
4. 同一画板或并列画板均可，仍不要说明装饰。
5. 新建画板 `icons-铃铛`，将图标组件放入画板。
6. 回复画板链接 + 组件名 + 跳过项。
