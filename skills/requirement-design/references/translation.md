# 英文文案（translation）

用于页面设计。填写英文文案前先阅读本文件。

## 规则

1. 先提取交互稿中的原始文案，再翻译；不得增加、删减或改变业务信息。
2. 同一含义的业务术语保持英文表达一致；同一中文词在不同语境下含义不同时，分别记录用途和译法。
3. 人名、ID、日期、角色缩写和业务数据保持原意。
4. 历史稿中已有、含义一致且已确认可用的英文术语，优先沿用。
5. 无法准确判断含义时，先向用户确认，不自行扩写。
6. 完成后检查拼写、单复数、时态、大小写和重复表达。
