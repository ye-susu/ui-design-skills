# 完成页面设计（design-pages）

用于步骤 6。进入本文件前，步骤 5 已完成页面设计任务整理，步骤 4 已完成历史稿复制或占位。

## 开始设计

1. 遵循 `design-system-use`。
2. 处理每个页面前，读取步骤 5 中该页面的设计内容，不重新整理改动清单。
3. 交互稿用于确认模块、信息层级、字段、状态、操作入口和文案。
4. 英文文案按 [translation.md](translation.md) 的规则填写。

## 无需调整页面

1. 读取步骤 5 的对比结论，确认历史稿与交互稿的模块、信息层级、字段、状态、操作入口和文案含义一致，且设计备注没有提出修改要求。
2. 保留已复制的历史稿，不新增、删除、替换或重新排列页面元素。

仅有字体、颜色、圆角等视觉表现差异，不作为需要迭代的依据。
未完成对比，或发现业务内容差异、明确的修改要求时，不得标记为“无需调整”。

## 设计迭代页面

确认无需调整页面后，先完成全部设计迭代页面。

对每一页：

1. 读取对应交互稿页面、设计备注和页面设计任务。
2. 打开本次 Section 中已复制的历史稿。
3. 保留历史稿原有的页面结构、布局、视觉样式和未涉及本次需求的模块。
4. 只修改步骤 5「设计内容」中明确列出的模块或元素。未列入修改范围的内容不得重新搭建、替换组件、调整布局或统一视觉样式。
5. 本次新增的模块必须按照 `design-system-use` 使用当前 Design System；修改历史模块时，在保持原有视觉和结构的基础上完成需求调整。
6. 任务仅涉及文案时，只修改设计任务中明确列出的文案，不额外调整页面结构。

## 全新设计页面

设计迭代页面全部完成后，再完成全新设计页面。

对每一页：

1. 读取对应交互稿页面、设计备注和页面设计任务。
2. 在本次 Section 中对应的 Frame 上从零完成设计；如该 Frame 来自历史稿，不沿用其页面结构。
3. 使用 Design System 从零完成页面结构和视觉设计。
4. 按交互稿确认模块、信息层级、字段、状态与文案。

不得复制无关业务页面后仅修改名称或文案，代替全新设计。

## 逐页对照检查

每页完成后，使用结构信息和页面截图，与页面清单、交互稿及设计备注逐项对照。

先检查内容：
- 重新对照交互稿，确认页面清单完整记录了本次页面应呈现的模块、字段、文案、操作、状态、重复数量及媒体内容；发现遗漏时补全清单并落实设计。
- 将清单中的各项内容与终稿逐项对应，应显示的内容不得遗漏、误隐藏、遮挡或裁切；应收起或隐藏的内容保持对应状态。长页面须检查完整内容，不能只检查首屏。
- 检查终稿是否存在无来源的业务内容，或未经需求说明就改变了展开状态、消息类型和文案含义。

再检查排版：
- 全新设计页面及设计迭代中新增或修改的模块，其模块顺序、内容分组及控件相对位置须与交互稿一致；未涉及本次需求的历史模块保持原有布局。
- 检查主要金额、页面标题和主要操作是否突出；辅助说明与提示不得无依据地抢占主信息层级。
- 检查相关内容是否成组、同类内容是否对齐、间距是否一致；不得通过删减内容或过大的空白制造简洁效果。
- 检查不同内容类型是否完整呈现，例如图文和大图消息不能被统一改成纯文字列表。
- 若终稿比参考稿更难识别主信息、理解分组或找到操作入口，记录具体问题并修正后再检查。

记录每页发现的漏项、位置不一致和视觉问题。修复后重新检查，全部通过后才能交付。

## 完成条件

- [ ] 页面清单中的每一页均已按其页面类型完成处理，并有对应视觉终稿；
- [ ] 无需调整页面已完成逐页对比，且未发生设计任务之外的修改；
- [ ] 设计迭代页面已完成步骤 5 设计任务中明确列出的全部改动；
- [ ] 设计迭代页面中，修改范围之外的页面结构、布局、样式和模块与历史稿保持一致；
- [ ] 全新设计页面已使用 Design System 从零完成；
- [ ] 每一页已完成与交互稿及设计备注的对照检查；
- [ ] 已完成术语对应关系检查；同一含义的业务术语保持英文表达一致，不同含义已分别记录；
- [ ] Section 内不存在占位 Frame 或临时文案；
- [ ] 已在适用范围内完成 `design-system-use` 的 QA；
- [ ] 已记录 Design System 复用项、缺失项和例外说明。

## 禁止事项

- 除步骤 5 经逐页对比确认的无需调整页面外，不得将历史稿或占位 Frame 直接作为终稿交付；
- 不得将未完成逐页对比的历史稿标记为“无需调整”；
- 不得用改名或替换文案代替尚未完成的其他设计改动；
- 不得保留步骤 5 明确要求删除或替换的历史模块、字段、Tabs 或状态；
- 不得使用无关业务页面代替全新设计页面；
- 不得未阅读交互稿和设计备注就声称页面已完成设计；
- 不得跳过逐页对照检查或 `design-system-use` QA。
