# 整理页面设计任务（design-task）

用于步骤 5。完成页面清单和历史稿复制后，读取交互稿中的设计备注，明确每一页的设计方式和设计内容。

## 整理内容

页面清单中的每一页都需记录：

| 页面名称 | 页面类型 | 历史稿 | 对比结论 | 设计备注 | 设计内容 |
|---|---|---|---|---|---|
| … | 无需调整 / 设计迭代 / 全新设计 | 来源 Frame / 无 | 一致项与差异项 | … | 保留、新增、替换或删除的内容 |

## 页面类型

- **无需调整**：将已复制的历史稿与交互稿逐页对比后，页面模块、信息层级、字段、状态、操作入口和文案含义均一致，且没有设计备注要求修改的内容。此类页面保留历史稿，不新增、删除、替换或重新排列页面元素。
- **设计迭代**：以已复制的历史稿为基础，按交互稿和设计备注完成明确的设计调整。
- **全新设计**：不沿用历史稿的页面结构，使用 Design System 从零完成设计。

页面类型以历史稿与交互稿的逐页对比结果为准；设计备注用于明确需要调整的内容。

没有历史稿时，页面类型为“全新设计”。交互稿、历史稿和设计备注仍不足以判断时，先向用户询问。

## 设计内容

以步骤 3 的页面清单为基础，记录本次具体处理事项：

- 无需调整页面：记录对比依据，设计内容填写“保留历史稿”。
- 设计迭代页面：列出需新增、修改、替换或删除的模块、元素及依据；其余内容保留。
- 全新设计页面：根据页面清单和设计备注，列出需要搭建的模块、字段、状态和操作入口。

已有记录直接引用，不重复抄写。
没有历史稿时，在对比结论中注明“无历史稿可对比”。

## 完成条件

- 每一页都已完成分类；有历史稿的页面已完成逐页对比，无历史稿的页面已注明“无历史稿可对比”；
- 每一页都有明确的设计内容；
- 设计任务已覆盖页面清单中的全部页面。
